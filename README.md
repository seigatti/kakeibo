# 家計簿 PWA（自分専用・費用ゼロ）

資産スナップショット（投資=マネーフォワード / 現金=Zaim / 年金）と月次収支を記録・グラフ化する自分専用アプリ。

```
[PWA (React+Chart.js)] ←JSON→ [GAS Web App API] ←→ [Googleスプレッドシート「家計簿DB」]
  GitHub Pages で配信            自分として実行           データ実体（Googleが自動バックアップ）
```

- **スマホでもPCでも同じURL**。ホーム画面に追加すればアプリとして起動
- **データは自分のGoogleドライブ上のシート**なので、端末が壊れても失われない
- 月額費用ゼロ（GitHub Pages / GAS / Google Sheets すべて無料枠）

## フォルダ構成

| パス | 内容 |
|---|---|
| `web/` | PWA フロントエンド（Vite + React + TypeScript + Chart.js） |
| `gas/Code.gs` | Google Apps Script（API サーバー。手動で貼り付けてデプロイ） |
| `migration/migrate.py` | 家計簿.xlsx → シートへの初回データ移行 |
| `.github/workflows/deploy.yml` | GitHub Pages 自動デプロイ |

## セットアップ手順（初回のみ）

### 1. GAS API のデプロイ（約5分）
1. https://script.google.com → 「新しいプロジェクト」
2. `gas/Code.gs` の内容をエディタに貼り付けて保存（プロジェクト名は「家計簿API」など）
3. 上部の関数選択で **`setup`** を選んで「実行」→ 権限を承認
4. 「実行ログ」に表示される **スプレッドシートURL** と **APIトークン** を控える
5. 「デプロイ」→「新しいデプロイ」→ 種類「**ウェブアプリ**」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
6. 発行された **ウェブアプリURL**（`https://script.google.com/macros/s/…/exec`）を控える

### 2. 既存Excelデータの移行（1コマンド）
```
python migration/migrate.py --upload --url <ウェブアプリURL> --token <APIトークン>
```
実行後、スプレッドシート「家計簿DB」に資産27件・変動費33ヶ月分・固定費14件が入る。

ふるさと納税（ふ納税_せ / ふ納税_あ）の移行は別コマンド（他のデータに影響しない）:
```
python migration/migrate_furusato.py --upload --url <ウェブアプリURL> --token <APIトークン>
```
※GASのコードを更新した後は、先に GASエディタで `setup` を再実行して新しいシート（furusato_items / furusato_years）を作成しておくこと。

### 3. GitHub Pages 公開
1. GitHub で新規リポジトリ作成（例: `kakeibo`。**Public**）
2. このフォルダを push:
   ```
   git remote add origin https://github.com/<ユーザー名>/kakeibo.git
   git push -u origin main
   ```
3. リポジトリの Settings → Pages → Source を「**GitHub Actions**」にする
4. Actions タブでデプロイ完了後、`https://<ユーザー名>.github.io/kakeibo/` にアクセス

※個人データ（xlsx・移行JSON）は `.gitignore` 済みでリポジトリには入らない。

### 4. アプリ初期設定
1. 公開URLを開き、設定タブで **ウェブアプリURL** と **APIトークン** を入力 → 「保存して接続テスト」
2. ホーム画面に追加:
   - iPhone: Safari で開き 共有 → 「ホーム画面に追加」
   - Android: Chrome で開き メニュー → 「アプリをインストール」
   - （端末ごとに初回だけ設定タブでURL/トークンの入力が必要）

### 5. ブックマークレット（転記を1タップに）
設定タブに表示されるコードをブックマークとして登録すると、
マネーフォワード/Zaim のページを開いた状態から1タップで数値入力済みの記録画面が開く。
詳しくはアプリの設定タブを参照。

## ふだんの使い方
- **ヘルプ**: 各画面の「？」マークをタップすると、その欄・グラフの計算式や前提（子供費用の標準額表・児童手当・税制の適用年など）が表示される
- **バランスシート**: 資産タブで負債（住宅ローン・奨学金など）を登録すると、ホームの「資産のグラフ」に純資産（資産−負債）の推移グラフが表示される。ローンは元利均等の返済スケジュールから各時点の残高を自動計算
- **ローンの総支払額**: 登録したローンについて、当初借入額に対して完済までにいくら払うか（総支払額＝元金＋利息総額・毎月返済額・完済予定月・支払済/残り）を資産タブとホームに表示。元金と利息の内訳は積み上げ棒グラフで比較できる（当初の借入条件どおりに返した場合の試算。繰上返済・金利変動は未反映）
- **資産配分**: ホームに投資/現金/年金の構成比をドーナツグラフで表示
- **ライフプラン**（プランタブ）: 世帯の総資産が80年後までどう推移するかをシミュレーション。基本生活費は空欄なら過去12ヶ月の実支出から自動推定。設定に名前を付けて保存し、シナリオ同士を比較（A/B）できる。運用利回りは投資分のみに複利適用。マイホーム購入（頭金・ローン・金利・修繕費・家賃控除・住宅ローン控除）や親の介護（カスタム収支のテンプレ）も反映可能。子供費用は児童手当（第3子加算対応）を自動差引き。インフレ率・運用利回り・昇給率・基本生活費、大人ごとの手取り年収（空欄なら「ふるさと」の給与データから手取りを自動想定）・収入ON/OFF・退職年齢・年金、子供の状況（保育園/公立私立/高卒大卒大学院/一人暮らし実家）、カスタム収支（車の買替など）をパラメタにして即時再計算。名目資産と実質資産（インフレで目減り後の今の価値）の2系列で表示。設定は「設定を保存」でシートに保存
- **プラン画面の構成**: 前提を「シナリオ」として保存し、見比べる画面。普段は**グラフと表だけ**を表示（主要指標／総資産の推移／資産の内訳推移（投資・現金）／年間の収入と支出／支出の内訳推移／ライフイベント年表／5年ごとのサマリ）。作成・修正は「✎ 編集」「＋ アンケートで新規作成」「＋ 手入力で新規作成」から**別画面**に入って行う。編集画面では**上書き保存**と**別名で保存**（＝複製）が選べ、キャンセルで元に戻る。以前の「現在の設定」は廃止し、初回に自動で「マイプラン」というシナリオへ移行される
- **ライフイベント年表**: 子供の進学・卒業、マイホーム購入・ローン完済、退職、年金受給開始、資産のピーク、資産がマイナスになる年を年順に一覧。**対象者ごとに色分け**され、年齢は「対象者 / 世帯主」を併記（世帯主は設定タブの控除プロフィールで選んだ人。未設定なら生年のある先頭の大人）
- **前提の厳しさ診断**（プランタブ）: シナリオの前提を1つずつ「一般的な標準値」に戻して80年分を計算し直し、**どの前提が結果をどれだけ悪くしているか**を影響の大きい順に表示する。各項目に「標準に合わせる」ボタンがあり、その値を当てた状態で編集画面が開く（すぐには保存されない）。「すべて標準に合わせる」もある。標準値は設定タブの「計算の基準値 → ライフプランの標準値」で出典つきで確認・変更できる
- **年金の上昇率**: 年金は物価にほぼ連動して改定されるため、新規シナリオの既定を**1.7%**（標準インフレ2% − マクロスライド0.3%）にしている。0%は受給額が生涯据え置きというかなり厳しい前提で、受給期間が長いと結果が大きく悪化する（保存済みシナリオの値は変わらないので、診断が指摘する）
- **退職後の基本生活費**: 全員が退職した年以降の基本生活費の割合を設定できる（既定100%＝変化なし）。家計調査では高齢無職世帯の消費支出は現役期より小さく、目安は70%程度
- **プランのA/B比較**: 保存したシナリオから **A（青の実線）と B（黄の破線）を選んで比較**できる。グラフの見出し・色チップ・凡例・差分表がすべてプラン名で表示されるので、どのプランとどのプランを見ているか一目で分かる（A に選んだシナリオがグラフ・表に反映される）
- **アンケートからシナリオ作成**（プランタブ）: 選択式の質問に答えるだけでシナリオを自動生成する専用画面。**簡易版9問**は「教育方針」「家計の方針」「将来の見通し」といった**大雑把な方針を選ぶだけで詳細版の複数項目がまとめて決まる**（子供の人数・住まい・車・老後の取り崩し・現金が足りないときの扱いは簡易版でも個別に選ぶ）。**詳細版17問**では方針の代わりに学校・進路・運用割合・運用スタイル・インフレ（1〜7%の8択）・**実質賃金**・退職年齢・生活費水準・税の見通し・一般的な支出・親の介護を1つずつ指定できる。**昇給率は「インフレ率＋実質賃金−税や社会保険料の負担増」で決まる**ので、実質賃金を横ばいにすれば昇給率＝インフレ率、マイナスにすればその分だけ手取りが実質目減りする想定になる。各質問の下に**その回答で何が決まるか**が表示され、簡易版から詳細版に切り替えると方針から展開された値が初期値として入る。できあがる設定をプレビューしてから名前を付けて作成できる
- **一般的な支出のテンプレ**: 住宅の大規模修繕（持ち家なら200万を15年ごと）・家電の買い替え（5万/年）・冠婚葬祭や帰省（10万/年）・医療費（大人ごとに60代10万→70代20万→80歳〜30万/年）を、アンケートの回答か編集画面の「＋ 一般的な支出をまとめて」ボタンで一括登録。「一般:」で始まる行だけが入れ替わるので、手入力した行は残る
- **投資へ回す割合**: 毎年の収入のうち何%を現金から投資分へ振り替えるかを設定でき、その分に運用利回りの複利が効く。振り替えるのは**その年の黒字の範囲まで**（赤字の年は投資に回さない）で、現金が足りない年は投資を取り崩して充てるため、現金がマイナスに沈むことはない（総資産は振替で増減しない）
- **投資の取り崩し**: 老後などに投資を計画的に現金化する設定。**率**（毎年の投資残高の◯%＝4%ルールなど）か**金額**（毎年◯円・物価に合わせて増額）を選び、**取り崩し開始年**を指定できる。取り崩しは投資から現金へ移すだけなのでその年の総資産は変わらない（減るのは将来の複利分）。**取り崩しを止める現金比率**も指定でき、現金 ÷（現金＋投資）がその割合以上の年は取り崩しを見送る（現金が十分あるうちは投資を売らない運用を表せる。0＝毎年ルールどおり取り崩す）
- **現金が足りないとき**: 取り崩しルールに従っても現金が不足する年の扱いを選べる。「投資から補う」（保ちたい現金の下限も指定可）か「補わない」（投資に手を付けず現金がマイナスのまま）
- **計算の基準値**（設定タブ）: ふるさと納税の上限計算やライフプランの試算に使う制度の数値・想定値（年金満額・子供費用・児童手当・マイホーム・各種控除など）をグループ別に編集できる。各項目に既定値の併記・出典サイトへのリンク（？内）・個別/一括リセット・毎年改定されうる値の「要確認」表示。所得税率など法定テーブルは参考表示。基準値はシートに保存され全端末共通
- **ホームにグラフ集約**: 各タブのグラフをホームに「資産／収支／消費量」の折りたたみセクションで一覧。画面上部の**表示期間バー1本**（今年／過去12ヶ月／全期間／期間指定・既定は全期間）がホームの全グラフに効き、スクロールするとヘッダー直下に貼り付いて画面下部までついてくる。貯蓄率の推移（期間内の最大・平均・最小つき）・支出のカテゴリ構成比・固定費の内訳（期間合計）・カテゴリ別の集計も表示。**記録が全く無い期間はグラフに出さない**ので、「全期間」でも空白が続かない（資産タブ・収支タブにも同じ期間バーがある）
- **今月の投資増減**: 資産記録に「今月の投資増減」欄を追加。マネフォ用ブックマークレットが画面の「今月 +○○円」（登録した投資系資産の前月比）を自動入力し、月ごとの推移を棒グラフで確認できる
- **消費量の記録**: 収支入力で電気(kWh)・水道(m³)・ガス(m³)・ガソリン(L)の使用量を金額と一緒に記録でき、消費量の推移と単価(円/kWh等)の推移をグラフで確認できる（データは専用シートに分離され、CSVインポートで消えない）
- **金額マスク**: ヘッダーの👁で全画面の金額表示（資産・収支・給与・ふるさと上限・グラフの数値・入力欄）を「＊」に切替。他人に画面を見せるときに使う。ON/OFFは全タブ共通でリロード後も維持
- **メモ**: ヘッダーの📝でフローティングメモを開閉。タイトルバーのドラッグで好きな位置に移動でき、スクロールやタブ切替でも画面上の同じ位置に固定される。メモ本体はGoogleシートに保存（位置と開閉状態は端末ごとに記憶）
- **資産の記録**: メール自動取込を設定すれば全自動（下記）。補助として、マネフォ・Zaimを開いてブックマークレットを1タップすると自動保存される（保存ボタン不要。同じ日にMF分とZaim分をタップしても1つの記録にマージされる）
- **収入**: 給与明細（収支タブ下部の「月次給与」カード）で総支給・控除・その他収入を人×月で入力。収入＝手取り（総支給−控除）＋その他収入で自動計算される（給料の直接入力欄は廃止）
- **収支の入力**（月1）: 変動費は収支タブで入力。過去分の一括登録は設定タブの「Zaim CSVインポート」でファイルを選ぶ（変動費のみ取り込み） → カテゴリの対応付けを確認（初回のみ。以後は記憶される）→ 登録。手入力する場合も「前月の値をコピー」で時短
- **固定費の変更**: 固定費タブで追加/編集。解約したものは「終了月」を入れると過去の集計を壊さない
- **月次給与**（収支タブ内のカード）: 管理者ごとに総支給・健保・厚年・雇用・所得税・住民税を月別入力（控除合計は自動計算、他月への一括コピー可）。未入力月は平均で補完して年収・社会保険料・手取りを自動想定し、収支の収入・ふるさとの上限計算・ライフプランに共通で使われる。ボーナスは「基準月額×か月分」または金額の手動入力（優先）で月ごとに設定
- **ふるさと納税**（ふるさとタブ）: 管理者（✎ボタンで自由に追加・名前変更可。名前変更時はデータも引き継がれる）と年を切り替えて上限額と寄付を管理。年収・社会保険料は手動優先・空欄なら給与データから自動採用。「この想定を上限計算に反映」→「上限情報を保存」で上限の目安に反映（税額通知書の正確な値があれば手動指定が優先）。上限計算には年ごとの生命保険料・地震保険料・医療費の**支払額**（控除額は自動計算）と、**控除プロフィール**（世帯で1つ：世帯主の選択・配偶者控除・扶養家族の生年・住宅ローン控除。家族系控除は世帯主にのみ適用）も反映でき、「計算の内訳を表示」で控除の内訳を確認できる。楽天の商品ページで専用ブックマークレット（設定タブ）をクリックすると商品名・金額・自治体・URLが入力済みの追加画面が開く。「未購入」ステータス＝候補リストとして管理され、購入したら年とステータスを更新する

## 資産記録の完全自動化（メール自動取込）

マネーフォワードのウィークリーメールをGASが毎日読み取り、資産を自動記録する。

1. マネーフォワード MEの設定 → メール配信 で「ウィークリーメール」をONにする（Gmail宛）
2. GASエディタに最新の `gas/Code.gs` を貼り直して保存
3. 関数 `importFromMail` を選んで一度手動実行 → Gmailへのアクセス権限を承認
   （メールが既に届いていれば、この時点でシートに記録される。取れない場合は実行ログに本文の先頭が出るので、その内容を開発者に共有して正規表現を調整する）
4. 左メニューの時計アイコン「トリガー」→「トリガーを追加」
   - 実行する関数: `importFromMail` / イベントのソース: 時間主導型 / タイマー: 日付ベース・午前6〜7時など
5. 以後、メールが届くたびに自動で assets に記録される（処理済みメールにはラベル「kakeibo取込済」が付く）

※マネフォの「資産総額」は年金を含むため、本文から年金額が取れた場合は 投資=総額−年金 として記録される（ブックマークレットも同じ扱い）。

## 開発
```
cd web
npm install
npm run dev     # http://localhost:5173
npm run build   # 本番ビルド (dist/)
```
GAS を修正した場合は script.google.com で貼り直し、「デプロイ」→「デプロイを管理」→ 既存デプロイを**編集して新バージョン**にする（新規デプロイにするとURLが変わるので注意）。
